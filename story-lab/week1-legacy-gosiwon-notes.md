# 1주차 — 현재 고시원 출발 (레거시 메모)

> 상태: **scenes.js에 현재 살아있는 버전.** 집 출발로 전환 시 여기 내용을 옮기거나 엔딩으로 이동.

## 지금 scenes.js에 있는 것 (2026-06-06 기준)
- 시작: `a1_wake` = `1막: 고시원`, 새벽 05:00, 배금날드 알바 출근
- `a1_mom_food` → `a1_mom_call` → 엄마 폰메시지 대화(화낸다/수긍/감사/돈빌린다 + 무시) — **잘 만들어짐, 재활용 가치 높음**
- `a1_bathroom` 거울 → 출근
- 그 뒤 1주차(w1_*) 버스정류장 헌팅 등

## 전환 시 처리
- **고시원 이미지/방 묘사** → 삭제하지 말고 **흙수저 엔딩(e_dirt) 공간**으로 이동. "추락한 뒤 거처"로.
- **엄마 폰메시지 루트** → 집 출발 버전으로 거의 그대로 이식.
- **매니저(점장) 전화/지각** → 축소/교체. 엄마·은행·통장 알림으로.
- 시작 배경만 집/원룸으로 교체하면 대부분 살아남음.

## 정리 대상 (죽은 코드)
- `w1_morning` + `w1_mom_*` (내가 1주차에 넣었던 옛 엄마 블록) — 엄마 루트가 a1로 이동하며 **고아**가 됨. validator가 `w1_morning` 고아로 경고 중. → patch로 제거.

## 주의
- 이 전환은 **새 레포·새 v 아님.** scenes.js 편집 몇 군데로 끝나는 수술. (current-direction.md §4)
