# 배금도시 V1 — 깊이 추가 계획 (주식·연출·성공 후)

> 방향 제안서. [yumina-arc.md](yumina-arc.md)(관계 척추) 위에 **주식 시스템·연출·성공 후 인생**을 얹는다.
> 코드보다 이 문서가 먼저. 동의/수정하면 단계별로 내려간다. 작성: 2026-06-08

---

## 0. 절대 안 깨는 원칙 (기존 결정 유지)

- **A안 결정론.** 종목·레버리지 결과는 **작가가 정함(랜덤 X).** 선택의 의미 = "어떤 정해진 결말로 가는가". 주사위는 없다.
- **선택지 중립 / 정답 힌트 금지.** UI로 정답을 칠하지 않는다. 대신 **종목토론방의 환호가 함정**(디제시스 미스디렉션) — 군중을 따르면 잃고, 조용히 생각하면 산다. 배금도시(군중이 돈·떡상을 숭배)의 주제와 정확히 맞음.
- **폰 턴제.** 씬→씬 단방향. 실시간 샌드박스 X. 주식앱도 "한 번 들어갔다 나오는" 연출.
- **관계 우선.** 모든 베팅은 사실 **유민아에게 거는 베팅.** 주식 시스템은 관계 아크를 떠받치는 도구지 주인공이 아니다.

## 1. 종목 시스템 — "선택별로 수익률이 달라진다" (결정론)

단일 종목 → **3종목 + 1선물(레버리지 전용)**. 각자 작가가 박아둔 운명.

| 종목 | 성격 | 종토방(군중) | 정해진 결과 | 티어 |
|---|---|---|---|---|
| **배금전자** | 우량주(현재 72,000) | 잔잔함 | ×1.4 (적정) | 생존 → 은수저 기본 |
| **누리바이오** | 테마주 | "내일 상한가" 도배·떡상 환호 | ×0.3 (−70% 폭락) | **함정** → 붕괴 |
| **한성2차전지** | 실적주 | 관심 적음·"노잼" | ×3.0 (대박) | 조용한 정답 → 금수저 후보 |
| **(선물/코인)** | 레버리지 전용 | 도박방 | 레버리지에 종속 | 대박 또는 청산 |

- **"조용한 정답"**(한성2차전지)은 종토방이 무시하는 종목. 힌트는 UI가 아니라 **세계 묘사**로만(예: 2주차 AI 대화에서 "사람들이 안 보는 데"를 흘리거나, 무덤덤한 공시 한 줄). 군중 추종 = 손실, 독립 사고 = 생존. 이게 "정답을 숨기되 운빨은 아닌" 결정론.
- **미매수(포기) 루트 재설계.** ⚠️ 지금은 포기 → 붕괴인데, 돈을 안 잃었는데 붕괴는 비논리. 포기 = **현상유지(가난하지만 빚 없음)** 루트로: "한 발도 못 뗐다 → 유민아를 만날 돈도 못 만든다 → 조용히 멀어짐". 별도 약한 엔딩(흙수저의 변주)으로.

## 2. 레버리지 — 같은 종목도 배율로 결말이 갈린다

주문창에 **레버리지 선택**(없음 / 3배 / 10배) 추가. 결과 배수와 **청산(반대매매)** 리스크를 같이 키운다.

| 종목 × 레버리지 | 결과 | 엔딩 티어 |
|---|---|---|
| 한성2차전지 ×무 | +적정 | 생존(은수저) |
| 한성2차전지 ×3~10 | **대박** | 금수저 후보(단, 5주차에 유민아를 미뤄야 금수저) |
| 배금전자 ×무 | +소폭 | 생존(은수저) |
| 누리바이오 ×무 | −70% | 붕괴(빌림 루트) |
| 누리바이오/잡주 ×10 | **청산** | 파멸 |
| 올인/분노베팅 ×고배 | 청산 | 파멸 |

- **연출:** 청산 시 폰에 "반대매매 안내" 푸시 + 평가손익 빨강 점멸. 레버리지 게이지 한 컷.
- 결정론 유지: 어떤 종목이 오를지는 고정. 레버리지는 그 고정 결과를 **증폭**할 뿐(운 아님).

## 3. 결과 → 4주차/엔딩 매핑 (엔진 remap 한 곳)

`w4_result`를 종목·레버리지·절제 플래그로 분기. 현재 `(stock_bought||temperance)?생존:붕괴`를 확장:

```
stock_pick + leverage →
  win_big   → 생존(B), 금수저 후보 (assets 大)
  win_small → 생존(B), 은수저 기본
  loss      → 붕괴(A), 유민아 빌림 루트
  liquidated→ 붕괴(A), 파멸 직행(빚 大)
  skip      → 현상유지(가난) → 흙수저 변주
```

엔딩 진입은 기존 5개(흙/한강/파멸/은/금) 유지. 티어가 **어느 엔딩 후보로 보낼지**만 정하고, 최종은 5주차 선택(유민아 vs 돈)이 마무리.

## 4. 연출 보완 (싸게 깊어지는 것들)

- **주식앱 화면:** 종목 리스트(각 등락률·색), 봉차트 한 컷, 체결/청산 푸시, 평가손익 빨강/파랑. (phone.js stockApp 확장)
- **두 시스템 묶기:** 3주차 데이트 중 울리는 알림이 **"내가 산 그 종목"의 실시간 손익**이 되게. 폰을 엎으면 관계+/손익 모름, 확인하면 관계−/숫자 봄 = 한 선택에 둘이 얽힘.
- **정서 게이지(기존 확장):** 배터리·시간·말풍선 길이·읽음. 손익이 커질수록 그의 말풍선이 길고 들뜨고, 청산 후엔 짧고 텅 빔.
- **분노 게이지 연동:** 큰 손실 → 분노↑ → 올인/레버리지 선택지 해금(기존 angerAtLeast 패턴 재사용).

## 5. 성공 후 인생 연출 (사용자 요청)

엔딩 카드 뒤 **"그 후" 에필로그 1~2컷.** 성공이 끝이 아니라는 걸 보여줌.

- **금수저 에필로그 — 텅 빈 펜트하우스.** 1년 뒤. 좋은 집, 좋은 차, 텅 빈 식탁. 폰엔 읽씹된 유민아 톡. "가질 수 있는 건 다 가졌는데, 이걸 같이 볼 사람이 없다." → 성공이 가장 추운 곳.
- **은수저 에필로그 — 반복되는 평범한 주말.** 유민아와 국밥, 시장, 작은 방. 통장은 안 늘지만 토요일이 돌아온다. "올라선 게 아니라, 서 있을 자리가 생겼다." → 유일하게 따뜻한 결말.
- **(선택) 흙수저/파멸 후일담:** 미납 독촉 푸시, 부재중. 짧고 차갑게.

## 6. 단계별 작업 순서 (동시편집 충돌 최소화)

> 사용자가 주식앱(scenes·phone·engine·validator)을 동시 편집 중 → **각 단계 시작 전 최신 상태 다시 읽기.**

- **Phase 1 — 종목 다양화.** ✅ 대부분 구현(2026-06-08, 94씬 통과):
  - 종목 3개 결정론: 배금전자 ×0.5(종토방 떡상 **함정**=손실) / 한성2차전지 ×2.5(조용한 **정답**=대박) / 누리바이오 ×1.3(무난). `w2_pick`에서 선택, `stock_pick` 플래그.
  - 종토방(`w2_community_open`) = 배금전자 떡상 도배 → 군중을 따르면 손실. 정답 힌트는 종목 한 줄 플레이버로만(중립 유지).
  - 결과: 수익 종목 = 기존 결과화면(상승 렌더 재사용), **손실/미매수 = 내러티브 씬**(phone.js 상승가정 렌더 회피 → phone.js 무수정).
  - 매핑: `engine.remap` — `w3_stock_result`(stock_pick별 결과), `w4_result`(stock_profit>0 = 생존, 손실/미매수 = 붕괴). 검증기 `REMAP_HUBS` 갱신.
  - ⬜ **남은 것: 미매수(포기) 현상유지 엔딩.** 지금은 포기→붕괴(w4a, 빚)인데 비논리. "가난하지만 빚 없음 → 유민아 못 잡음" 별도 약엔딩 필요(branchMap 6번째 추가 검토).
  - ⬜ (선택) phone.js 결과화면 손실 렌더(빨강/마이너스 부호) 지원하면 손실도 앱 화면으로 보여줄 수 있음 — 현재는 내러티브로 우회.
- **Phase 2 — 레버리지 + 청산 연출.** 주문창 레버리지 선택, 청산 푸시.
- **Phase 3 — 관계×주식 연동.** 데이트 알림 = 내 종목 손익.
- **Phase 4 — 성공 후 에필로그.** 금/은 후일담 시퀀스.

**추천 시작: Phase 1** (스토리 가치 제일 크고 코드 충돌 제일 적음). 종목 선택이 의미를 갖는 순간 게임 전체가 깊어진다.
