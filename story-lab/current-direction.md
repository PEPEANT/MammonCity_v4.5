## 0. 한 줄 정체성
돈 숭배 도시에서, 스물다섯 청년이 돈 때문에 **자기 자신과 가족의 신뢰를 태우는** 이야기.
시스템 게임이 아니라 **사람이 망가지는 걸 매 턴 지켜보는** 이야기. → 의미가 해자.

## 1. 주인공
- **20살, 막 군대에서 전역, 회귀 없음, 특수능력 없음.** (옛 25/26살 한서기·회귀·차트보는눈 = 폐기)
- 동기: 연애가 하고 싶다 → 돈이 필요하다 → 절박함에 투자/도박 → 자기파괴.
- 진짜 주제: 돈이 아니라 **인정받고 싶은 마음.**

## 2. 구조 (확정)
```
1주차 → 2주차 → 3주차 ──→ 4주차 ┬ 분기A(붕괴) ┬ 5주차 → 흙수저
   (직선, 공통)                  │            ├ 5주차 → 한강
                                │            └ 5주차 → 파멸
                                └ 분기B(생존) ┬ 5주차 → 은수저
                                             └ 5주차 → 금수저
```
- 엔딩 5개: **흙수저 / 한강 / 파멸 / 은수저 / 금수저**
- 숨겨진 해방형 엔딩, AI로 각성하는 흐름, 판을 읽는 식의 해석 대사는 V1에서 삭제. 붕괴 루트는 해방이 아니라 **그냥 파멸**로 닫는다.

## 3. 핵심 규칙 (절대 위반 금지)
- **투자 = A안.** 주식/코인/카지노는 **조작형 시스템 아님.** 결과는 **랜덤 아니라 작가가 정함(결정론적 분기).** 단 결정론 ≠ 선택 없음 — 플레이어 선택(절제vs폭주, 엄마 대응)이 어떤 정해진 결과로 갈지를 가름. **B(확률)·C(상시 폰앱) = V1 금지.**
- **결과는 숫자 아니라 인간관계/방/엄마/거울/폰에 구체적 물건 하나로.** (`-8만원 알림`❌ → `엄마 반찬이 굳어 있고 캔이 하나 늘었다`✅)
- **폰 = 턴제.** 씬→다음씬 단방향. 자유조작 샌드박스 금지.
- **선택지 = 중립.** 색으로 정답/극단 힌트 금지. 감정(분노 등)은 별도 게이지로.
- **매 턴 = 최소 1개의 "관찰되는 변화"** (거울/폰/엄마/매장/물건/말투). 플레이어가 아니라 세계가 움직임 = 통제된 자유.

## 4. 무대 · 인물
- **시작점:** 고시원 출발 유지(에셋이 꽉 찬 유일한 곳).
- **유민아 = V1 본선 히로인(2026-06-08 확정).** 정류장에서 만남 → 톡·데이트 → 데이트 중 돈에 정신 팔리는 균열 → 그녀에게 돈 빌림 → 잃음. affection 키 `yumina`. "돈이 필요한 이유"이자 "돈 때문에 잃는 것" = 자기파괴의 얼굴.
- **돈 빌림 = 엄마→유민아로 이전.** 4주차 붕괴 때 유민아에게 빌림(`w4a_yumina_borrow`). 빌리면 관계가 식음 = 후폭풍. (엄마 아침 냉장고씬은 **삭제됨**.)
- **엄마:** V1 본선에서 빠짐. 후반 나락/V2 여지만 남김. ※ 새 세션은 엄마 아침씬을 **다시 넣지 말 것.**

## 5. 범위 (V1 / V2)
- **V1 = 자기파괴**(주식·도박·폭주·빚·분노맥스 → 본인·가족만 태움). 단순하게 먼저 출시.
- **V2 = 타인파괴/괴물화**(사기·성매매·마약·여론). "결핍이 메뉴를 낳는" 시스템. 전부 보류.
