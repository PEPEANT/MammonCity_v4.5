## 0. 한 줄 정체성 (개정)
**배금도시 = 경제 시뮬이 아니라 "차트로 움직이는 도시."**
돈 숭배 도시의 심장박동이 차트다. **감정이 세계를 바꾸고, 세계는 무관심하게 무너진다.**
(주제는 그대로: 인정받고 싶은 마음 → 돈 → 자기파괴. 단 *전달 방식*을 차트-도시로 통일.)

---

## 1. 새로 확정한 핵심 원리 3개 (이번 대화의 결론)

**① 감정 = 세계를 보는 렌즈. (직접 행동이 아니다.)**
분노가 차면 주인공이 매수 버튼을 누르는 게 아니라 → **세계가 먹이를 던진다.** 유튜브가 "OO코인 열풍!"을 띄우고, 주변이 다 산다. 현실의 알고리즘 급진화·도박 중독 작동 방식 그대로. → **세계가 움직임, 주인공이 아니라.** 이게 흔한 트레이딩 게임과 가르는 해자.

**② 접근이 "상태"로 열린다. (샌드박스 딜레마 해소)**
거래소는 항상 있는 게 아니다. **분노가 불러낼 때 열린다.** ("OO코인 거래소 열람!") 접근 자체가 서사적 결과이므로 "상시 폰앱=샌드박스" 문제가 성립 안 함. → 결핍이 메뉴를 낳되, 작가가 한 번 열어주는 **통제된** 형태.

**③ 차트-도시 / regime(국면) 시스템.**
- 평소(관측 안 됨): **±5~10% 노이즈 드리프트.** 일부러 밋밋. 최적화할 게 없음.
- 챕터 클리어 = **측정(관측).** 파동 붕괴 → **국면 전환 + 폭발 등락폭.**
- 국면 4종: 상승 / 횡보 / 하락 / 💥폭발.
- **국면의 누적 기울기 = 엔딩.** 계속 하락으로 기울면 흙수저, 버티면 은/금.

## 2. 표준 수직 루프 (1주차 예시 — 코인)

```
분노 게이지 ↑  (인간관계 챕터에서 누적)
  → [폰을 본다]  알고리즘이 코인 열풍을 먹임      ← 세계가 반응(원리①)
  → 사회적 압력: "다들 산다" 반복 노출 (종토방/유튜브)
  → 표류 → 홈 복귀 → "OO코인 거래소 열람!"        ← 상태가 접근을 연다(원리②)
  → 매수 결정                                      ← off-ramp. 여기서 '공범'이 된다
  → 분기: 분노 × 돈 × 행동 → A / B / C            ← 발산
  → [거시 사건] 트럼프 관세 발표 = 작가가 정함, 무조건 온다
  → 붕괴: -99% / 상폐                              ← 다시 수렴 (노출량만큼만 잃음)
  → 결과가 방·엄마·거울에 새겨진다
```
모양 = **다이아몬드(발산→수렴)**. 한 주의 완결 슬라이스.

## 3. 반드시 지키는 craft 3원칙 (안 지키면 무너지는 지점)

**① 폭락은 운명, 노출량은 선택.** (exposure, not outcome)
거시 붕괴는 누가 뭘 했든 온다 = 세계는 너한테 무관심하다. 플레이어 선택이 정하는 건 *붕괴 여부*가 아니라 **얼마나 노출됐나.** 분노 풀→몰빵→-99%가 전 재산. 절제→소액→생존. **세계는 안 변해주지만, 네 감정이 세계가 너를 얼마나 가져갈지를 정했다.**

**② 보이는 off-ramp → 관객이 아니라 공범.**
탈출구(절제/꺼버리기)가 *무시하고 싶게* 눈에 보여야 한다. 없으면 플레이어는 cutscene 보는 관객, 있는데 안 누르면 공범. **비극은 공범에게서 나온다.**

**③ 발산 후 수렴 + 반응형 표면은 하나만.**
- 분기는 다이아몬드로 **다시 모은다.** 안 그러면 5주차×4엔딩 콘텐츠가 지수폭발 → 못 끝냄.
- "감정이 세계를 바꾼다"를 **모든 표면에 하지 마.** **폰 피드 하나만** 상태반응형, 나머지(거리·엄마 대사 대부분)는 정적. 진짜 반응형 1개 > 반쯤 반응형 10개.

## 4. 깊이 예산 — B(심리)에 다 쏟고 A(시뮬)엔 0

| 깊게 판다 (B · 심리적 장악력) | 가짜/얕게 둔다 (A · 시뮬 정확도 = 함정) |
|---|---|
| 숨쉬는 차트(regime 드리프트+노이즈) | 호가창·체결·시장 깊이 |
| 종토방(FOMO·"가즈아"·물린개미 곡소리) | 수십 종목 독립 펀더멘털 시뮬 |
| regime 연동 뉴스 헤드라인(확신 주입) | 실시간 가격 발견·타 에이전트 |
| 올인 순간의 긴장(새벽 2시·배터리 11%·엄마 부재중) | 코인거래소+카지노 동시(= 옛 breadth 실패) |
| 챕터→국면 전환(나비효과) | 아무 때나 자유 거래(샌드박스) |

- **종목 이름은 많게(벽지·분위기), 시뮬은 적게.** 실제로 얽히는 건 **1~3개.** 벽지 종목은 관측 안 되니 노이즈로 깜빡여도 됨.
- "AI가 엔진 짠다"는 사실 — 단, 비싼 건 코드가 아니라 **5주×4엔딩 콘텐츠·튜닝·일관성.** 그래서 **스키마부터 잠그고**(regime 4종, 종목/뉴스 형식) 콘텐츠를 채운다.

## 5. 원본 대비 무엇이 바뀌나 (← 짚고 넘어갈 지점)

- 🔄 **[변경] "C(상시 폰앱) V1 금지" → "서사로 열리는 거래소는 V1 허용."**
  근거: 접근이 *상태의 결과*라 샌드박스가 아님(원리②). 자유조작은 여전히 금지.
- 🔄 **[완화] "폰=완전 턴제" → 앰비언트 차트 층만 실시간 허용.** 결정적 베팅은 여전히 서사 게이트.
- ➕ **[신규] 차트-도시 정체성 / regime 시스템 / 감정-렌즈 / exposure 원리 / craft 3원칙.**
- ✅ **[유지] 결정론(랜덤 아님·작가가 정함) · 세계가 움직임 · 중립 선택지 · 결과는 물건·관계로 · 진엔딩 4개 구조.**
- ❌ **[기각] 다종목 시뮬 · 뉴스 생성엔진 · 코인거래소+카지노 동시.** (breadth 함정, A로의 추락)
