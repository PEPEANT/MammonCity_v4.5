# 배금도시

웹 기반 선택형 스토리 게임. (HTML/CSS/JS → 나중에 Capacitor로 플레이스토어 출시)

## 지금 바로 실행
`game/index.html` 을 **더블클릭**해서 브라우저로 열면 끝. (설치·서버 불필요)

## 폴더 구조
```
game/
  index.html      화면 뼈대
  style.css        레퍼런스 레이아웃 (세로 폰 / 헤더 / 이미지 / 텍스트·버튼)
  engine.js        엔진 — 한 번 만들고 거의 안 건드림
  data/scenes.js   ★ 스토리 데이터. 여기만 늘리면 게임이 늘어남
  assets/          그림·음악 파일 (지금은 비어 있음 → placeholder 박스로 표시)
```

## 스토리 추가하는 법 (네가 할 일)
`data/scenes.js` 의 `scenes` 안에 씬을 추가하고 `next` 로 연결한다.
형식 설명은 파일 맨 위 주석에 다 있음. 막히면 AI한테 "이런 씬 추가해줘" 하면 됨.

## 그림 넣는 법
- 지금은 모든 그림이 **placeholder 박스**(점선 + 설명)로 보임 = "여기 무슨 그림" 샷리스트.
- AI로 그림을 뽑아 `assets/` 에 넣고, 씬의 `image` 를 `"assets/파일명.png"` 로 바꾸면 자동 교체.
  (예: `p2`, `p5` 는 이미 실제 경로로 연결해둠 → 파일만 넣으면 바로 보임)

## 들어있는 기능
- 타이틀 / 이어하기(자동 저장) / 앨범
- 캐릭터 생성 (성·이름 입력)
- 프롤로그 카드 → 대사 진행 → 호감도 선택지 → 엔딩 카드
- 호감도 시스템 (선택지가 유민아 호감도를 올림 → 관계 라벨로 표시)
- 앨범 해금 (특정 씬 지나면 그림 해금)
