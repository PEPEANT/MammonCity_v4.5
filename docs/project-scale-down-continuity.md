# Project Scale-Down Continuity

## One-Line Conclusion

시뮬라크월드와 배금도시의 연속성은 유지하되, 당분간 프로젝트 규모는 거대한 온라인 게임이 아니라 소설/만화 중심의 작은 제작 단위로 줄인다.

## Current Rule

특이점레이스가 사실상 마무리된 이후, 당분간 새 거대 온라인 프로젝트를 시작하지 않는다.

하지만 시뮬라크월드와 배금도시를 버리는 것은 아니다.

## What Continues

- 시뮬라크월드 세계관.
- 배금도시 세계관.
- 특이점레이스가 남긴 완성물/대표작 성격.
- 배금도시 원고와 코어 문서.
- 캐릭터, 테마, 감정 엔진.
- 프로젝트를 포트폴리오 증거물로 정리하는 흐름.

## What Changes

- 거대한 온라인 기능 개발은 당분간 중단한다.
- 새 게임 모드, 공통 엔진, 대형 관리자 시스템을 벌리지 않는다.
- 컴퓨터 매각 이후에도 이어갈 수 있는 제작 단위로 바꾼다.
- 중심 작업은 소설, 만화, 콘티, 세계관 문서, 포트폴리오 정리로 축소한다.

## Practical Meaning

대형 개발 환경이 사라져도 프로젝트는 끊기지 않는다.

이후 작업은 노트북, PC방, 모바일, 문서 편집 환경에서도 가능한 작은 산출물 중심으로 이어간다.

## Guardrail

규모를 줄이는 것은 포기가 아니다. 연속성을 유지하기 위해 제작 단위를 작게 만드는 것이다.
