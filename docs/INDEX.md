## Context

현재 작업 결론은 "공통 엔진 개발"이 아니라 "특이점레이스 v0.1 완성"이다. 미래 확장은 포기하지 않되, 지금은 코드로 새 확장을 시작하지 않는다.

특이점레이스 마무리 이후에는 거대한 온라인 개발을 계속 벌이지 않고, 배금도시/시뮬라크월드의 연속성을 소설, 만화, 콘티, 문서 중심의 작은 제작 단위로 이어간다.

배금도시를 게임 프로토타입으로 다룰 때도 대형 자유 시스템으로 확장하지 않는다. 돈, 주식, 코인, 도박은 사람의 말과 분위기를 읽는 스토리 선택지 안에서만 처리한다.
