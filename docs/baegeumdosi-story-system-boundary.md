# Baegeumdosi Story System Boundary

## One-Line Conclusion

배금도시는 자유 스마트폰 샌드박스가 아니라, 인간 심리 신호를 읽고 돈으로 선택하는 턴제 분기형 스토리 게임으로 만든다.

## Purpose

v1에서 스마트폰, 앱 설치, 주식, 코인, 도박 기능이 자유 메뉴처럼 붙으면서 스토리 중심이 흐려졌다.

이번 버전은 같은 길로 가지 않기 위해 시스템보다 장면을 먼저 고정한다. 주식, 코인, 도박, 뉴스, 스마트폰은 별도 놀이판이 아니라 사람의 말과 분위기, 욕망을 보여주는 장면 장치다.

## Current Rules

- 자유 스마트폰 메뉴를 만들지 않는다.
- 앱 설치, 앱 목록, 상시 접속 가능한 증권/코인/도박 메뉴를 만들지 않는다.
- 모든 돈 선택은 스토리 장면 안에서만 발생한다.
- 모든 돈 선택 전에는 사람의 말, 뉴스, 커뮤니티 반응, 표정, 분위기 같은 인간 심리 신호가 먼저 나온다.
- 이미지가 이미 보여주는 물건, 장소, 화면 속 글자는 본문에서 다시 설명하지 않는다.
- 본문은 이미지가 못 말하는 감정, 해석, 압박, 다음 행동의 이유만 쓴다.
- 선택지가 있는 장면은 본문을 먼저 타이핑 연출로 보여준다. 탭하면 본문을 넘긴 상태로 처리하고, 다음 상태에서는 대사/지문 없이 선택지 버튼만 띄운다.
- 매수, 매도, 숏, 코인, 도박, 일하기 선택은 턴을 소비한다.
- 결과는 돈뿐 아니라 관계, 평판, 플래그, 다음 장면에 영향을 준다.
- 투자 결과는 단순 정답 맞히기가 아니라 주인공이 인간 욕망을 어떻게 해석했는지의 결과로 보인다.

## Smartphone Rule

스마트폰은 메뉴 허브가 아니다.

허용되는 사용:

- 주인공이 폰을 보는 컷신.
- 뉴스 헤드라인, 차트, 커뮤니티 반응을 보여주는 연출.
- 선택지 직전의 정보 제시.
- 기억 앱, 증권 앱 같은 세계관 장치가 짧게 열리는 장면.
- 엄마, 점장, 지인과의 메시지 대화. 단, 유저가 직접 타이핑하지 않고 대사 선택지로 답장을 고른다.

금지되는 사용:

- 유저가 언제든 여는 자유 스마트폰.
- 앱을 설치하고 앱 안에서 별도 게임을 반복하는 구조.
- 자유 타이핑 채팅.
- 스토리 없이 주식, 코인, 도박만 계속하는 미니 시뮬레이터.
- 돈 벌기 기능이 본편 대사와 분기보다 앞서는 구조.

## Core Flow

장면은 아래 순서로 작성한다.

1. 사람이 말한다.
2. 주변 분위기나 욕망이 드러난다.
3. 주인공이 돈의 신호로 해석한다.
4. 선택지가 나온다.
5. 턴, 돈, 관계, 플래그가 변한다.
6. 다음 장면에서 후폭풍이 보인다.

예시:

```text
편의점 아주머니:
"오늘 삼성전자 대박이더라. 우리 조카도 샀대."

손님:
"그러니까 말이야. 이제라도 들어가야 하나?"

주인공:
'모두가 말하기 시작했다. 이건 고점 시그널이다.'

선택지:
1. 삼성전자를 숏친다.
2. 관망한다.
3. 아주머니에게 위험하다고 말한다.
4. 돈이 무서워 편의점 일에 집중한다.
```

## Scene Data Pattern

`game/data/scenes.js`의 선택지는 아래처럼 작게 붙인다.

씬 본문은 일러스트의 캡션이 아니다. 예를 들어 냉장고 쪽지 이미지에 "냉장고에 밥해놨다. 보고 전화해라."가 이미 보이면, 본문에는 그 문구를 반복하지 않고 "엄마 글씨였다."처럼 보이지 않는 의미만 남긴다.

```js
{
  label: "삼성전자를 숏친다.",
  next: "samsung_short_result",
  effects: {
    cash: 180000,
    turn: 1,
    flags: { firstShort: true }
  }
}
```

엔진의 현재 저장 구조는 `player`, `progress`, `economy`, `records`, `flags`, `history`를 가진다. 랭킹은 나중에 붙이더라도 자유 앱 플레이 결과가 아니라 `records.leaderboardScore` 같은 스토리 진행 결과를 제출한다.

## Guardrail

배금도시의 재미는 "주식 기능이 많다"가 아니다.

핵심은 돈 앞에서 사람들이 어떤 말을 하고, 주인공이 그 말을 어떻게 읽고, 그 선택이 관계와 인생을 어떻게 바꾸는지다.
