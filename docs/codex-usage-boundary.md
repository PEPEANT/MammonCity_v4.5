# Codex Usage Boundary

## One-Line Conclusion

Codex는 인생회의와 장기 감정분석이 아니라, 특이점레이스 완성에 쓴다.

## Current Decision

토큰은 아깝다. 하지만 Codex는 쓸 곳을 좁히면 무기다.

지금 Codex의 사용처는 하나다.

특이점레이스 완성.

## Use Codex For

- 실행 오류 수정.
- 모바일/PC 기본 동작 확인.
- 방 생성, 입장, 시작, 종료 플로우 안정화.
- 랭킹, 채팅, 캐릭터 선택의 최소 안정화.
- 배포 경로 오류 수정.
- 콘솔 에러 제거.
- README/배포 안내 정리.
- 특이점레이스 smoke 테스트 유지.

## Do Not Use Codex For

- 인생회의.
- 감정분석 장기 대화.
- AI 미래 철학 확장.
- 시뮬라크월드 거대 통합 구상.
- 관리자페이지 대규모 재부착.
- 배금도시 전체 확장.
- 수복 대규모 개선.
- 인생 아카이브 MD 대공사.
- 새 프로젝트 시작.

## Decision Filter

Codex에게 요청하기 전에 한 문장으로 확인한다.

이 요청이 특이점레이스를 배포 가능한 상태로 만드는가?

대답이 "예"이면 Codex를 쓴다. 아니면 보류한다.

## Practical Rule

생각하는 데 쓰는 AI 비용은 줄이고, 완성하는 데 쓰는 AI 비용만 남긴다.
